# Shared Controls / 共性合规控制

这些主题可能同时影响 Apple App Store、Google Play 和当地法律，但具体平台义务仍需分别核对。

## Core topics / 核心主题

- Privacy and data protection / 隐私与数据保护
- Account creation and deletion / 账户创建与删除
- Permissions and consent / 权限与同意
- User-generated content and moderation / 用户生成内容与审核
- Children and age-sensitive experiences / 儿童与年龄敏感体验
- Payments, subscriptions and refunds / 付款、订阅与退款
- Third-party SDK and supply-chain transparency / 第三方 SDK 与供应链透明度
- Security, abuse prevention and incident response / 安全、滥用防护与事件响应

## Editorial rule / 编辑规则

Shared documents describe the cross-platform control objective. Platform-specific documents describe the exact Apple or Google implementation and submission requirement. Do not infer that passing one platform automatically satisfies the other.
