## 5. How to read a page / 如何阅读

导入的专题保留快照里的小节结构，没有改写成同一套标题。先看标题和导入说明或语言差异，再看范围和义务，最后用页内官方链接回到当前原文。知识库中的摘要、编辑译文和执行建议不替代平台原文或当地法律。

Phase 1 的短页（隐私基线、Data Safety baseline、审核准备、提交前快速检查）使用“范围 / 核心结论 / 必须做什么 / 证据”这一类标题。
