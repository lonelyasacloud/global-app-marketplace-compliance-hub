## 这篇页面应该回答什么

1. App、后端和 SDK 链路收集哪些数据？
2. 每种数据为什么收集、共享？
3. 隐私政策和 Data Safety 表单如何披露？
4. 审核所需的删除、同意、拒绝流程证据是否准备好？
5. 哪些是当前要求，哪些只是未来生效预告？

## 发布证据清单

- 覆盖 App、后端、SDK 和第三方的数据流清单。
- 将 Data Safety 每个字段映射到实际运行行为。
- App 内和商店页面都能访问隐私政策。
- 账号删除和数据删除测试证据。
- 同意、拒绝、撤回以及地区差异的测试证据。
- 对特殊权限、数据流或地区差异的审核备注。

## 常见失败模式

- 把 Data Safety 表单当成 User Data 政策的替代品。
- 只申报客户端，遗漏后端或 SDK 的数据收集。
- 复制上一个版本的申报，没有核对当前构建版本。
- 把未来生效日期混入当前发布门禁。
- 遇到不确定性时不披露部分覆盖范围。
