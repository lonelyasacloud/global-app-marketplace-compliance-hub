# Regions / 地区要求

地区文档用于记录当地法律、监管来源、平台店面差异、适用用户范围、有效日期和发布控制。

## Initial coverage / 首批覆盖

- European Union
- United States
- China
- Brazil

后续地区可以按用户、收入、发行店面或高风险功能增加。地区文档必须说明“适用地区”和“触发条件”，不能把某一地区要求泛化为全球要求。

## Required fields / 必备字段

- jurisdiction and affected storefront
- covered users and app categories
- obligation or restriction
- effective date and deadline
- official legal or regulator source
- Apple/Google implementation impact
- evidence and owner
- last reviewed and next review date
