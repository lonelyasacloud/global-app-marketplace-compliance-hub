# Policy Deadlines / 政策日期

日期记录必须区分：

- 生效日期
- 强制截止日期
- 个案通知期限
- 平台迁移窗口
- 内部完成日期
- 下一次复核日期

每个日期都需要来源 URL、适用平台、地区、对象、触发条件和证据状态。新闻中的计划日期、帮助页中的正式日期、Console 中的账号级日期可能不同；冲突时全部保留并标注，不要静默选择一个日期。

任何日期进入发布计划前，必须重新核对当前官方页面。
