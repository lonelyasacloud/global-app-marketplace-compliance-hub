# Google Play / Google Play 应用商店

本目录收录 2026-10-24 Google Play 知识库快照里已经导入的双语专题，加上 Phase 1 的 Data Safety baseline。完整清单、证据等级和语言差异在下面的专题表。语言差异的逐页记录在[快照清单](https://github.com/lonelyasacloud/global-app-marketplace-compliance-hub/blob/main/data/sources/google-play-kb-snapshot-2026-10-24.md)。

英文官方页面是效力来源。中文专题是编辑改写，除非该页写明中文官方正文确已打开。`kb_checked_at` 是快照源文件记录的核对日，不是本次导入时重新打开线上页面的日期。现行 Play 规则与未来生效的预告分开，包括 2027-01-27 的联系人、精确位置、SMS/通话记录电话验证和地理围栏前台服务。离线 Wiki、递归链接图、URL 审计 CSV 和来源台账没有导入本仓库。

## Start here / 从这里开始

1. [Developer Distribution Agreement / 开发者分发协议](developer-distribution-agreement/developer-distribution-agreement.zh-CN.md) · [English](developer-distribution-agreement/developer-distribution-agreement.en-US.md)。英文协议文本控制译文。

3. [User Data / 用户数据](user-data/user-data.zh-CN.md) · [English](user-data/user-data.en-US.md)，以及 Data Safety 的 [baseline / 基线](data-safety/data-safety-baseline.zh-CN.md) · [English](data-safety/data-safety-baseline.en-US.md) 与 [form / 表单](data-safety/data-safety.zh-CN.md) · [English](data-safety/data-safety.en-US.md)。表单申报不替代 User Data 政策。
4. [Payments / 付款与订阅](payments/payments-and-subscriptions.zh-CN.md) · [English](payments/payments-and-subscriptions.en-US.md)，然后是 [release workflow / 发布流程](publishing/play-release-workflow.zh-CN.md) · [English](publishing/play-release-workflow.en-US.md)。
5. 权限与目标 API 各自独立，不并入 User Data： [sensitive permissions](sensitive-permissions/sensitive-permissions.zh-CN.md)、[declaration](permissions-declaration/permissions-declaration.zh-CN.md)、[background location](background-location/background-location.zh-CN.md)、[SMS and Call Log](sms-call-log/sms-call-log.zh-CN.md)、[photo and video](photo-video-permissions/photo-video-permissions.zh-CN.md)、[contacts and foreground location](contacts-location-permissions/contacts-location-permissions.zh-CN.md)、[account deletion](account-deletion/account-deletion.zh-CN.md)、[target API](target-api/target-api-level.zh-CN.md)。联系人与前台位置页是快照中的政策预告，不是核对日已经生效的现行规则。
6. 内容、儿童与执行各自独立： [UGC](user-generated-content/user-generated-content.zh-CN.md)、[inappropriate content](inappropriate-content/inappropriate-content.zh-CN.md)、[content ratings](content-ratings/content-ratings.zh-CN.md)、[deceptive behavior](deceptive-behavior/deceptive-behavior.zh-CN.md)、[age and child safety](age-restricted-child-safety/age-restricted-child-safety.zh-CN.md)、[Families ads SDK program](families-self-certified-ads-program/families-self-certified-ads-program.zh-CN.md)、[DSA transparency](child-safety-dsa-transparency/child-safety-dsa-transparency.zh-CN.md)（监管材料，不是 Play 规则）、[regional reporting](child-safety-regional-reporting/child-safety-regional-reporting.zh-CN.md)（举报目录，不是 Play 规则）、[enforcement](enforcement-and-appeals/enforcement-and-appeals.zh-CN.md)（操作流程，不替代协议或政策）。
7. 其余专题按表内分组查阅：广告与完整性、健康与 SDK、受限商业与地区分发、Play Console 与商店呈现、质量与平台计划、目录与公告。Play Policy Insights 是官方开发者工具，不是 Play 政策正文。政策档案和公告是历史材料。预测市场试点不替代赌博政策。Play Books 出版政策不是 Android 应用审核政策。

每行专题的证据等级、语言差异和需要与 2027-01-27 分开的日期写在表的 Evidence 与 Snapshot review 列，不在这里重复。第 5–6 步只链了中文页，对应英文页在同一行的 English 列。
