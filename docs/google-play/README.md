## Snapshot note / 快照说明

Google batch 1 从 2026-10-24 Google Play Knowledge Base 快照导入开发者分发协议、合并版开发者计划政策、User Data、Data safety 表单、付款与发布流程这六个专题。表中的 Data Safety baseline 仍是 Phase 1 页面。Google batch 2 从同一快照再导入敏感权限、权限声明、后台位置、SMS 与通话记录、照片与视频权限、账号删除和目标 API。这些页面的 `kb_checked_at` 是快照源文件记录的核对日，不是本次导入时对线上页面的重新复核。英文官方页面是效力来源。中文专题正文是编辑改写，不是 Google 已发布中文页面的逐字文本。

语言差异（读不到的 `zh-CN` 路由、AI 翻译提示、分发协议中文日期格式异常，以及第 16.1 条英文控制译文）写在各页导入说明和[快照清单](../../data/sources/google-play-kb-snapshot-2026-10-24.md)中。Batch 2 里，敏感权限和目标 API 的 Play Help `zh-CN` 路由在快照中未能读取。SMS/通话记录的中文页无法稳定抓取，中文稿依据英文正文；同时 `hl=zh-Hans` 页仍显示旧例外表，这不表示 2027-01-27 的日期被取消。账号删除的精确 `hl=zh-CN` 路由未能读取，核对使用的是已打开的 `hl=zh-Hans` 页面。权限声明的简体中文页已打开。后台位置和照片/视频主文没有记录 `hl=zh-CN` 抓取失败。敏感权限和 SMS/通话记录同时保留现行规则与 2027-01-27 生效的预告，两类日期不合并。抓取失败不表示政策已经变更。

Google batch 3 从同一快照再导入用户生成内容、不当内容、内容分级、欺骗性行为、年龄限制与儿童安全、Families 自认证广告 SDK 计划、儿童安全 DSA 透明度、儿童安全地区举报目录，以及执行、申诉与 EEA 调解。这些页面的 `kb_checked_at` 仍是快照源文件记录的核对日，不是本次导入时对线上页面的重新复核。DSA 透明度是监管和行业材料，地区举报目录是路径查找辅助；两者都不是 Play 政策。Families 广告 SDK 计划是操作要求，不替代 Families 政策。执行与申诉是操作流程，不替代分发协议或开发者计划政策。Android API 与 AdMob 配置仍是实现说明。

Batch 3 的语言差异：UGC 的英文和 `zh-Hans` 正文已打开，页面提示中文可能由 AI 翻译，精确 `zh-CN` 路由不可读。年龄限制政策的英文和 `zh-Hans` 正文已打开，中文页提示可能为 AI 翻译。不当内容的中文 URL 被重定向到 `zh-Hans`，并提示可能为 AI 翻译；英文受限内容目录返回 HTTP 429。内容分级的简体中文页不可读，中文稿依据英文来源；YAML 核对日是 2026-10-23，英文开篇写 2026-10-22。欺骗性行为快照只记录已打开的英文帮助页，没有记录已核对的中文官方页面；所链接的权限预告于 2027-01-27 生效，不是本政策的现行文本。Families 计划的英文和 `zh-Hans` 页面已打开；水印与测试应用文章的中文直接抓取返回 Internal Error。执行专题记录的是已打开的英文帮助正文，没有记录已核对的中文官方执行页面；YAML 核对日是 2026-10-23，开篇写 2026-10-22。DSA 与地区举报目录的主要来源是英文官方页面，快照没有记录对应的已核对中文官方页面。抓取失败和日期差异不表示政策已经变更。年龄限制页的 2026-08-26、COPPA 的 2026-04-22 和 Texas SB 2420 的 2026-01-01 在源文件中都已生效或已过，不与 2027-01-27 的权限预告合并。Families 计划在快照中暂停新申请，但没有记录重新开放日期。

合并版 Developer Program Policy 在该快照中的生效日是 2026-09-30。更早政策措辞不作为现行规则。

开发者分发协议、开发者计划政策、Play Console 发布步骤和 Data Safety 申报保持为不同专题。敏感权限、权限声明、后台位置、SMS 与通话记录、照片与视频权限、账号删除和目标 API 也各自独立，不并入 User Data 或 Data Safety。用户生成内容、不当内容、内容分级、欺骗性行为、年龄限制与儿童安全、Families 自认证广告 SDK 计划、DSA 透明度、地区举报目录，以及执行与申诉同样各自独立。
