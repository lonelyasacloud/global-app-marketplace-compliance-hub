> **导入说明（Google batch 3）。** 本页正文取自 2026-10-24 Google Play 知识库快照里已经分开的对应语言改写（`play.deceptive-behavior`，核对日 2026-10-22），不是官方页面的逐字文本。英文官方来源是效力来源。`kb_checked_at` 使用快照源文件记录的核对日；本次导入没有重新打开线上官方页面。文中“本知识库”“本库”“本地专题”描述的是该快照知识库的覆盖范围，不是本仓库已经导入的页面清单。快照里指向尚未导入本仓库的专题、链接图、台账或 CSV 的相对链接，已改为文字提及；指向 Google batch 1、batch 2 或本批九个专题的相对链接已改到本仓库路径。快照记录的是 2026-10-22 核对的现行英文帮助页。它没有记录已核对的中文官方欺骗性行为页面。本中文页是快照对该英文文章的编辑改写，不是 Google 已发布的中文页面文本。源文件所引 2025-04-10 公告写明，其对操纵媒体的澄清不是新的或更新的政策。所链接的 2026 年 4 月权限预告把联系人与位置变更排在 2027-01-27；该预告不是现行欺骗性行为文本，两类日期保持分开。本政策是 `normative`。虚假陈述、用户数据、敏感权限、设备滥用和目标 API 仍是独立专题。

## 政策范围

现行英文帮助页为[Deceptive Behavior](https://support.google.com/googleplay/android-developer/answer/17006354?hl=en)。旧链接 [answer/16680223](https://support.google.com/googleplay/android-developer/answer/16680223?hl=en) 已重定向到新版。页面把政策分为误导性声明、欺骗性修改设备设置、促成不诚实行为、操纵媒体和行为透明度五部分。应用本体、第三方 SDK、广告和服务都要符合规则。

**与“虚假陈述”区分：** 欺骗性行为涵盖用户实际体验、设备设置、欺诈工具、操纵媒体、隐藏功能和规避审核；Misrepresentation（快照：`misrepresentation.md`，未导入本仓库） 是并列的独立政策主题，需同时核对商店页、开发者/政府身份声明等具体规则。

## 五类禁止行为与核验要点

| 政策分支 | 主要要求 |
| --- | --- |
| 误导性声明 | 名称、图标、描述、截图、视频、分类和评级应准确反映真实功能。禁止虚构无法实现的功能、错误分类、无授权宣称“官方”或伪称政府关联，也禁止可能干扰选举的可证伪虚假信息。 |
| 欺骗性修改设备设置 | 在应用外更改系统/浏览器设置、书签、快捷方式、小组件或桌面呈现前须取得用户明确知情和同意；改动须容易撤销。不得以广告或第三方服务为目的修改，也不得误导/奖励用户卸载或停用其他应用；可核验的安全服务例外需满足政策条件。 |
| 促成不诚实行为 | 不得帮助生成假身份证件、护照、文凭、社保号、信用卡、银行账户或驾照；不得仿冒其他应用/网站诱取凭证、展示未经同意的个人信息、隐瞒关键的地区/设备差异或在版本大改时不告知用户。新增下载资源前须提示用户并明确下载大小。 |
| 操纵媒体 | 不得制作、传播或协助制作可能对敏感事件、政治、社会议题造成伤害的可证伪误导性图像、音频、视频或文字。公共利益、明显虚构、清楚可见的用户提示/水印、讽刺或戏仿可能构成例外，但仍须符合[受限内容政策](../inappropriate-content/inappropriate-content.zh-CN.md)。 |
| 行为透明度 | 不得藏入隐藏、休眠、未记录的功能，也不得侦测审核环境、动态下载并执行审核时不存在的新功能或混淆代码以逃避审核。应用须按商店页描述工作；应能向 Google 清楚解释应用功能和代码（包括 SDK）的用途。 |

## 检查流程

1. 用真实运行的 APK/AAB、服务端配置、广告和第三方 SDK 对照商店名称、描述、截图、视频与分类，查出无法实现或按地区/设备变化但未披露的功能。
2. 检查是否有假登录页、仿冒系统警告、未授权政府/品牌声明、动态功能开关或审核环境差异；确保审查员看到的行为与普通用户一致。
3. 逐项审查应用外设备设置、后台下载、远端脚本/代码及自动化改动：是否核心必需、用户是否明确同意、能否轻松撤回、下载大小是否事前披露。
4. 对生成/编辑/传播图像、音频、视频和文本的功能，检查敏感事件语境、清晰水印/免责声明、讽刺语境及受限内容政策。
5. 将本专题与虚假陈述（快照：`misrepresentation.md`，未导入本仓库）、移动垃圾软件/设备滥用（快照：`mobile-unwanted-software.md`，未导入本仓库）、[用户数据](../user-data/user-data.zh-CN.md)及商店素材最佳实践（快照：`store-listing-best-practices.md`，未导入本仓库）一起复核。

## 核验边界

现行帮助页及其直接政策目录已打开；问卷 cache miss，Google 内部图片受 SSO 限制，帮助社区/Console 入口仅作辅助，不能证明应用通过审核。Restricted Content 与 Privacy/Deception 分类页面下的各主题已进入知识库，但它们各自的更深 API、地区法规、动态表单和侧栏链接仍按来源台账继续核验。
