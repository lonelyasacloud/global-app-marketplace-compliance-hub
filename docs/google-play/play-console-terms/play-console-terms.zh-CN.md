## 与 DDA、API 条款的关系

- Play Console Terms 适用于个人用户使用 Console；接受者须年满 18 岁且达到所在国家/地区签订有约束力合同的年龄。它是 [DDA](../developer-distribution-agreement/developer-distribution-agreement.zh-CN.md) 的附加条款；使用 Console 也必须接受 DDA。
- 如代表公司或其他实体接受 DDA，接受者须有权代表该实体。Console Terms 将 Account Owner 定义为最初创建开发者账号的人，将 Console User 定义为该账号下的其他个人用户。
- Console Terms、DDA，以及使用 Google Play Developer APIs 时适用的 [Developer API Terms](https://developers.google.com/android-publisher/terms)共同构成 Console 使用的法律协议。Console Terms 对这组文件之间的冲突规定了优先顺序；API 用户还须遵守 Developer API Terms 和通用 [Google APIs Terms](https://developers.google.com/terms)。不要将 Console Terms、DDA、Developer Program Policies 或 API 专用条款混为一份文档。

## 使用信息与账号审计

Google 将 Console 和 Developer API 使用信息与开发者账号关联。条款举例包括页面访问和查看的数据、Console 功能操作、API 操作、登录邮箱、IP 地址及时间戳。Google 可以把这些信息提供给 Account Owner，用于管理账号、审计操作和发现潜在滥用。应用转移到新账号后，相关使用信息也会关联到新账号，并可向新 Account Owner 提供；只要关联开发者账号仍处于活动状态，条款就允许继续保留该信息，即使某个用户失去 Console 权限或登录被停用。

这与 Console 中的用户权限和 Activity log 相互关联：账号所有者应按最小权限配置用户，并在授权、撤权和账号转移时考虑可见的操作记录。见[Play Console 用户与权限专题](../play-console-user-permissions/play-console-user-permissions.zh-CN.md)。

## 使用限制、条款修改与终止

- 不得超出 Console 预期功能使用 Console；不得借 Console 从事、推广非法活动或滥用；不得禁用、干扰、逆向工程或规避 Console；也不得以违反其他 Google 服务条款的方式访问其他 Google 服务。
- Google 可更改、停止或限制 Console 的功能。条款修改会在 Console 和联系邮箱通知；既有用户通常在通知载明日期生效，且一般不少于发布后 30 天；新功能变化或法律要求的变化可立即生效。继续使用即表示接受修改。
- 不接受条款修改时，条款列出的专属补救方式是停止使用 Console。违反条款可导致 Console 访问终止；在适用法律允许范围内，Google 也可提前 30 天通知后因其他原因终止访问。
- DDA 规定的管辖法律和法院也适用于 Console Terms 相关请求；若使用 API，仍须并行读取 API ToS。

## 与其他 Play 要求的边界

Play Console Terms 管理 Console 用户对管理工具的使用、Console 使用信息及服务变更；DDA 管理开发者通过 Play 分发产品的合同关系；Developer Program Policies 管理应用/账号合规；Developer API Terms 对特定 API 增加用途限制。接受 Console Terms 或 DDA 不代表应用已通过审核，也不免除政策申报、隐私或当地法律要求。
