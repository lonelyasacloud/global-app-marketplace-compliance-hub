# Apple 审核准备 / Apple Review Readiness

## 审核前重点

- 提交构建与商店元数据、截图、预览和实际发布体验一致。
- App Review Information 说明 App 用途、核心流程、特殊硬件、地区差异和复现步骤。
- 需要登录时提供真实可用的演示账号、权限、测试数据、验证码/MFA 说明和重置方式。
- 需要付费、订阅或特定配置时，提供可复现的进入路径、测试商品和审核备注。
- 隐私政策、支持页面、账户删除和必要后端服务在审核期间可访问。
- 不存在隐藏、休眠、审核后才打开或未披露功能；远程配置不能改变审核所见的关键体验。
- 年龄分级、儿童、UGC、健康、金融、VPN、赌博、加密资产和其他受监管能力准备证明材料。

## 元数据与资产

名称、描述、关键词、截图、预览、App 内活动和创意素材应准确反映当前版本、适用受众和真实功能。价格、折扣、比较对象和效果承诺必须可验证并符合适用规则。

## 证据

保留最终构建标识、测试设备矩阵、账号说明、审核备注、配置快照、隐私和 SDK 清单、IAP 测试记录、地区差异和提交状态。
