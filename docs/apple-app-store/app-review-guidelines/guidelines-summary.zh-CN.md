## 适用范围

- App Store 审核覆盖 App、更新、App 内购买项目、活动、元数据及提交内容。开发者对广告网络、分析服务和第三方 SDK 的行为负责。
- 指南会持续更新。部分规则只适用于 iOS/iPadOS 替代分发与公证，不能把这类范围写成全球 App Store 的统一义务。
- 上架地区的当地法律同时适用。Apple 指南与法律义务是并行要求，不能互相替代。

## 1. 安全

### 1.1 令人反感或有害的内容

不得发布诽谤、歧视、恶意、露骨色情、鼓励暴力或危险行为、误导性宗教内容、虚假设备信息或恶作剧功能，或利用暴力冲突、恐袭、疫情等事件牟利的有害内容。标注“仅供娱乐”不能掩盖虚假功能。赌博、色情、人口贩卖和剥削相关内容需特别审慎。

**编辑译文：** 新版英文政策把非自愿亲密影像和 “nudification” 类功能纳入安全执行重点。这句中文不是 2026-06-08 中文官方页的原文。

### 1.2 用户生成内容与创作者内容

- 具备发布前或发布时的违规内容过滤，便于举报并及时响应，可屏蔽滥用用户，并公布有效联系信息。
- 开发者负责按指南、服务条款和社区标准移除违规内容。严重或重复失职可能导致下架或开发者账户处罚。
- 以色情、随机或匿名聊天、物化真人、威胁或霸凌为主要用途的 UGC 服务不适合 App Store。
- **编辑译文：** AI 内容创作服务也属于需要处理 UGC 风险的类型。创作者内容不能改变原生 App 的核心功能；付费内容要清楚标示。
- 创作者 App 要能识别超出 App 年龄分级的内容，并用已验证或用户声明年龄机制限制未成年人访问。

### 1.3 儿童类别

儿童类别 App 应以儿童为目标用户设计。外链、购买入口和其他可能分散儿童注意力的内容需放入家长监控区域。选择退出儿童类别，不会自动解除此前形成的用户预期。需遵守儿童隐私法。儿童类别 App 通常不应包含第三方广告或分析，也不得向第三方传送儿童个人或设备信息。有限例外须满足指南规定的严格条件。

### 1.4 人身伤害

健康、医疗或诊断类功能可能接受更严格审查。准确性声明要有可核实的方法和证据。仅凭设备传感器宣称测量血压、血糖、血氧、体温或 X 光等不可接受。适当提示用户向医生咨询；已有监管许可的，应提交证明。药物剂量计算器须来自合资格机构或获监管批准。不得鼓励未成年人使用烟草、电子烟、非法药物或过量饮酒。有牌照要求的服务须提供适用地区许可。不得鼓励危险挑战或酒驾。

### 1.5–1.7 开发者信息、安全与犯罪举报

提供准确、可用的支持联系信息。妥善保护依法或按协议收集的数据。用于举报涉嫌犯罪的 App 必须有当地执法机关参与，并且只在该参与机制有效的地区提供。**地区敏感。**

## 2. 性能

| 条款 | 摘要 |
| --- | --- |
| 2.1 完整性 | 提交可发布的完整版本。元数据和 URL 有效。无占位内容、崩溃或明显技术问题。登录 App 提供有效演示账户；审核期间后端服务必须可用。不能提供账户时，需事先获得 Apple 同意后提供全功能演示模式。IAP 应已配置、可见且可审查。 |
| 2.2 Beta 测试 | Beta、试用和演示版本使用 TestFlight，不作为 App Store 正式版本提交。TestFlight 分发仍受审核规则约束，不得以任何形式向测试员付费。 |
| 2.3 元数据准确 | 名称、描述、隐私信息、图标、截图、预览和活动要真实呈现实际体验。新功能写入审核备注并可供审核。名称最多 30 个字符。不得堆砌关键词或滥用他人商标。截图需展示实际使用。素材须适合所有受众。2.3.14 的创意素材补充见上文编辑译文。 |
| 2.4 硬件兼容 | 尽可能支持 iPad。避免异常耗电、过热或损害设备。不得运行无关后台任务。macOS App Store 应用还需遵守沙盒、打包、自动启动、下载代码、权限、更新及本地化要求。 |
| 2.5 软件要求 | 仅用公共 API，并按用途使用。遵守沙盒与容器边界。除符合条件的教育编程例外外，不下载会改变 App 功能的代码。后台服务只用于正当用途。支持 IPv6-only。网页浏览采用 WebKit；地区或资格适用的替代引擎须申请授权。通话拦截、面容识别、录制、组件广告、Matter 和广告展示均有专项限制。**编辑译文：** 2.5.19 明确禁止隐藏、休眠或未披露功能。 |

## 3. 业务

### 3.1 付款与 App 内购买

- App 内数字功能、内容、订阅和虚拟货币通常应使用 App 内购买。不能用自建解锁方式绕过规则。可恢复的购买须提供恢复机制。已购点数不能过期。随机虚拟物品在购买前披露概率。
- 数字商品或服务、实体商品或服务、人与人实时服务、企业服务、多平台服务和“阅读器”App 适用不同规则与例外。按交易本质分类，不能只看付款页面或商户。
- **地区敏感：** 外部购买链接、替代支付和第三方分发取决于店面、平台、授权资格和当前协议。美国店面和部分地区可能适用不同规定。不能把地区例外推广成全球规则。3.1.1(a) 的英文修订见上文编辑译文。
- 订阅需持续提供价值，周期至少 7 天，并可在用户的设备上使用。清楚披露价格、权益、周期、试用、自动续订和取消方式。不得诱导用户误订阅，也不能剥夺老用户已付费购买的核心功能。

参考：[自动续期订阅](https://developer.apple.com/app-store/subscriptions/)、[Developer Program 许可协议](https://developer.apple.com/support/terms/apple-developer-program-license-agreement/)、[阅读器 App](https://developer.apple.com/support/reader-apps/)、[外部购买](https://developer.apple.com/documentation/storekit/external-purchase)。协议层摘要见[许可协议主题](../developer-program/license-agreement.zh-CN.md)。

### 3.2 其他商业模式

商店目录式 App、刷广告展示或点击、没有合理依据地限制用户、操纵其他服务排名、未经许可募款等可能被拒。金融、借贷、加密资产、交易所、捐赠、保险和虚拟资产等领域要核对开发者主体资格、牌照、地域限制、披露和支付流程。**地区敏感。** 业务模式如不明显，应在元数据和审核备注中说明。这是执行提示，不是额外的 Apple 规则文本。

## 4. 设计

| 条款 | 摘要 |
| --- | --- |
| 4.1–4.3 | 不抄袭或冒充其他 App。不要把同一 App 拆成大量近似 Bundle ID。成熟、低差异品类需要有实质改进，不能为占位、刷量或重复提交。 |
| 4.4–4.6 | 扩展需真实有用并准确披露，不得在扩展内做营销、广告或 IAP。不得把 Apple 服务用于垃圾信息、钓鱼或未经同意的营销。通知不得成为使用 App 的强制条件。 |
| 4.7 | 宿主 App 开发者对 mini apps、小游戏、流媒体游戏、聊天机器人、插件和模拟器负责。需要隐私保护、内容审核、举报、屏蔽、合规付费、目录和通用链接、年龄限制，且不得未经同意共享原生 API 或隐私权限。 |
| 4.8–4.10 | 使用第三方或社交登录建立主账户时，通常需提供符合条件的等效登录选项，包括隐藏邮箱能力；指南列有例外。Apple Pay 交易前需披露重要购买信息。禁止把硬件或系统内置能力，或 Apple 服务本身商品化。 |

## 5. 法律

### 5.1 隐私

- 在 App 内和 App Store Connect 元数据中提供易访问的隐私政策。说明收集什么、如何收集、用途、第三方共享、保留与删除、撤回同意，以及用户如何要求删除数据。
- 数据收集前取得适当同意。用途字符串要具体、完整。不得以提供付费功能为条件，强迫用户授权与该功能无关的数据访问。
- 未经明确告知和许可，不得把个人数据提供给第三方，包括第三方 AI。不得擅自改变用途、反推匿名身份，或把通讯录、照片等建成自用或出售的数据库。跟踪需获得 ATT 许可。
- 若 App 支持创建账户，需在 App 内提供账户删除入口，并实际完成删除，或说明合法保留例外。删除不等于仅停用、退出登录或隐藏账户。
- 儿童数据、健康研究数据、位置、通话与短信数据、设备权限有额外限制。第三方 SDK 的行为也由开发者负责。

参考：[用户隐私和数据使用](https://developer.apple.com/app-store/user-privacy-and-data-use/)、[账户删除](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion)、[用途字符串](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-purpose-strings)。

### 5.2–5.6 知识产权、受监管类别与开发者行为

- **知识产权：** 仅使用自己创作或获许可的素材。第三方站点、内容或媒体下载需要相应授权。不得暗示 Apple 背书或仿造 Apple 产品。
- **游戏、赌博和彩票：** 由开发者赞助活动并提供正式规则。真钱博彩和彩票须有牌照、地域控制，且 App 免费提供。遵守真实货币游戏限制。**地区敏感。**
- **VPN 与 MDM：** 使用规定 API，满足提供者资格和地区许可。购买或使用前清楚披露数据收集和用途。严格限制数据出售、使用和共享。**地区敏感。**
- **开发者行为准则：** 诚实呈现开发者和产品。不得骚扰或欺诈。不得操纵评论、排名、搜索、推荐，或退款与购买体验。
- **审核后的责任：** 通过后仍须持续运行、保持质量，并随政策变化更新。严重安全或法律问题可能影响下架与账户状态。
- **编辑译文：** 被认定助长人口贩卖或剥削儿童的 App 将被下架并禁止替代分发；极端情形会通知有关部门。

## 提交前后（执行提示）

这些步骤来自指南对完整、可复现审核的要求，不是另一套 Apple 规则。

**提交前：** 完成稳定性测试。元数据准确，截图反映实际使用，支持链接有效。准备审核账户、演示路径、地区与设备差异、第三方服务和授权证明。审核期间后端可访问。审核备注解释不明显的功能与商业模式。

**提交后：** 在 App Store Connect 查看状态。对拒审用事实、复现步骤和对应条款沟通。确有紧急业务需要时才申请加急。不同意结果时走正式申诉。符合条件的已上架 App 错误修复可询问 Bug Fix Submission。
