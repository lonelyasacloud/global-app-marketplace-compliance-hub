# Apple App Store / Apple 应用商店

本目录整理 Apple App Review、App Store Connect 和相关开发者协议的双语摘要与执行材料。

## Priority reading path / 推荐阅读顺序

1. App Review Guidelines and guideline changes
2. Pre-submission review materials and demo-account readiness
3. App Privacy Details, Privacy Manifest and Required Reason API
4. App metadata, screenshots, age ratings and creative assets
5. Payments, subscriptions, external purchase and regional terms
6. UGC, children, regulated categories, security and intellectual property
7. Review status, rejection response and appeal evidence
